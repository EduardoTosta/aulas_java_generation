
# Aulas Java - Generation Brasil 

Este repositório contém exercícios, exemplos e conteúdos desenvolvidos durante a trilha de **Java** da [Generation Brasil](https://brazil.generation.org/).  
Aqui você encontrará códigos comentados e organizados por aula, com foco na prática de conceitos fundamentais da linguagem Java e no desenvolvimento de habilidades em programação orientada a objetos.

---

## 📂 Estrutura do Repositório

Os conteúdos estão organizados em pastas, seguindo a numeração e temas das aulas:

- `helloworld/`: Primeiro contato com Java, estrutura básica de um programa.
- `aula_02/`: Variáveis, tipos primitivos e entrada de dados.
- `aula_03/`: Operadores lógicos, condicionais e estruturas de decisão.
- `aula_04/`: Estruturas de repetição (for, while, do-while).
- `aula_05/`: Vetores e arrays multidimensionais.
- *(mais pastas serão adicionadas conforme as aulas avançam)*

---

## 🧠 Tecnologias e Conceitos Abordados

- Sintaxe básica do Java
- Entrada e saída de dados
- Estruturas de controle (if, switch, loops)
- Vetores e matrizes
- Orientação a Objetos (futuro)
- Boas práticas de codificação

---

## 🚀 Como executar os exemplos

1. Certifique-se de ter o **Java JDK** instalado na sua máquina (versão 11 ou superior).
2. Clone o repositório:

```bash
git clone https://github.com/EduardoTosta/aulas_java_generation.git
```

3. Navegue até a pasta desejada:

```bash
cd aulas_java_generation/aula_03/
```

4. Compile e execute o arquivo `.java` desejado:

```bash
javac Exemplo.java
java Exemplo
```
